## Usage guidance for collaborating AI tools

1. Treat the brand owner's supplied logo composition as the approved visual reference.
2. Preserve the feminine fine-line silhouette, champagne finish, LENGTA wordmark and exact tagline.
3. Do not redesign the logo, change the silhouette concept, alter spelling, or introduce unrelated icons without explicit approval.
4. Use the SVG for scalable previews, but note its font fallback. Do not treat it as final outlined lettering or a pixel-exact master.
5. Do not fabricate transparent-background, monochrome, embroidery or foil-ready variants from the reference without checking legibility and construction.
6. For web use, export optimized SVG/PNG/WebP after checking font rendering and small-size legibility.
7. For print, produce outlined vector masters and test at actual label, clasp and packaging sizes.
8. Keep the original high-resolution source file unchanged when it is added to the repository.
9. This logo belongs exclusively to LENGTA. Do not merge it with VYRA, SAXI or ParisShoes.
10. Do not change or publish the live website based on this package.
