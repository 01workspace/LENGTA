# LENGTA Asset Library

Use this directory for approved and working brand assets.

## Suggested structure
- `logo/` — editable logo masters and approved SVG/PNG/PDF exports
- `campaigns/` — campaign originals, selects, and approved exports
- `products/` — product photography and detail imagery
- `packaging/` — packaging artwork and print-ready files
- `social/` — approved social media exports
- `references/` — clearly labeled inspiration and research (not owned brand assets)

## Asset record
For every production asset, record:
- Filename and description
- Status: draft, working direction, or approved
- Creator / photographer
- License or written permission
- Model release status where applicable
- Allowed channels, territory, and duration
- Original/master file location

Do not upload third-party images, fonts, music, or artwork unless usage rights permit it. Keep original high-resolution files; create optimized web copies separately. Never store passwords, private customer data, or API keys here.
