# LENGTA — OWN THE BEAUTY.

This storefront mirrors the approved LENGTA website published as Tiniest Cloud `length-preview`, version 2.

## Visual parity
- The homepage, collection page, philosophy page, shared layout and global stylesheet are carried over from the approved Tiniest Cloud source.
- The same campaign, product, model and detail image selections are used under `public/assets/`.
- The approved LENGTA visual system is preserved: Obsidian, Blood Wine, Oxblood, Bone and Antique Champagne; Bodoni Moda and Manrope; editorial spacing, sticky header, hover transitions and responsive layouts.

## Build
```sh
npm install
npm run build
```

## Commerce status
The collection remains an editorial preview. Product specifications, prices, sizes, stock, checkout and payment flows are not represented as live commerce until the business details are approved.
