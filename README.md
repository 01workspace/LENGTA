# LENGTA — OWN THE BEAUTY.

This storefront mirrors the approved LENGTA website published as Tiniest Cloud `length-preview`, version 2.

## Visual parity
- The homepage, collection page, philosophy page, shared header/footer and global stylesheet are ported from the approved Tiniest Cloud source.
- The same campaign, product, model and detail image selections are served locally under `public/assets/`.
- The dark editorial design, type, spacing, sticky navigation, mobile menu, hover transitions and responsive layouts are preserved.

## Build
```sh
npm install
npm run build
```

## Commerce status
The collection remains an editorial preview. Product specifications, prices, sizes, stock, checkout and payment flows are not represented as live commerce until approved.
