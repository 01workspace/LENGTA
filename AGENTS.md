# LENGTA storefront — Tiniest Cloud

The LENGTA website is an Astro static storefront. Build with `npm run build`; Tiniest Cloud builds source deployments. Keep the brand distinct from VYRA and SAXI. The only approved brand identity is LENGTA — OWN THE BEAUTY.

## Asset map
- `public/assets/lengta-logo.webp`: transparent LENGTA logo for header, footer and favicon.
- `campaign-01-hero.webp` to `campaign-04.webp`: supplied LENGTA website campaign banners.
- `product-01-*`: AFTER DARK burgundy lace editorial, mannequin set and garment details.
- `product-02-*`: LENGTA bodysuit and front/back model views.
- `product-04-*`: black nightwear hero and feature images.
- `product-06-*`: black sheer nightwear editorial front/back views.

Explicitly branded VYRA or SAXI imagery has been excluded. Do not move those assets into this site.

Do not invent final product prices, stock, sizes, materials, delivery promises, checkout or payment functionality. All product names and copy on the collection page are marked as visual/editorial previews until commercial information is approved.
